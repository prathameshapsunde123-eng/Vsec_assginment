FORMATTED WEB DEVELOPMENT ASSIGNMENTS
=====================================

All HTML, CSS, JSON and selected JavaScript files have been formatted with line breaks
and indentation for easier reading in VS Code.

Open the project folder in VS Code. To reformat a file:
- Mac: Shift + Option + F
- Windows: Shift + Alt + F

If prompted, install/select Prettier as the formatter.

Projects:
- Assignments 1–4: open each index.html file in your browser.
- Assignments 6–7: open the folder in Terminal, then run npm install and npm run dev.
- Assignment 8: follow assignment8-student-api/README.md to configure MongoDB and start the API.
