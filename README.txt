WEB DEVELOPMENT PRACTICAL ASSIGNMENTS 1–8
===========================================

Prepared for: Prathamesh Baban Apsunde
Department: Information Technology
College: MVPS’s KBT College of Engineering, Nashik

This package includes eight beginner-friendly, practical assignments with a consistent,
modern visual style and personal/college branding. Fictional demo student names have been
removed. The student list in Assignment 2 uses the provided student identity; other forms
are ready for real entries.

ASSIGNMENT 1 — Responsive HTML5 + CSS3 page
  Open assignment1-responsive/index.html in a browser.

ASSIGNMENT 2 — Navbar, table and form
  Open assignment2-navbar-table-form/index.html in a browser.

ASSIGNMENT 3 — Student Result Management
  Open assignment3-student-results/index.html. Add marks to calculate totals, percentages,
  maintain the table and identify the topper. Data remains in browser memory until refresh.

ASSIGNMENT 4 — Employee Registration Form
  Open assignment4-employee-registration/index.html. JavaScript validates name, email,
  password, phone and department.

ASSIGNMENT 5 — Git and GitHub
  Follow assignment5-git/README.md and replace the GitHub repository placeholders.

ASSIGNMENT 6 — React Student Information
  In assignment6-react-students run:
    npm install
    npm run dev

ASSIGNMENT 7 — React Expense Tracker
  In assignment7-react-expenses run:
    npm install
    npm run dev
  Includes totals, category analysis and delete action. Data is stored in React state only.

ASSIGNMENT 8 — Student CRUD REST API
  Follow assignment8-student-api/README.md. Configure .env, connect MongoDB, run npm install
  and npm run dev, then test endpoints with Postman.

NOTES
- Use Node.js for React and API projects.
- For Assignment 8, ensure MongoDB is running or use a MongoDB Atlas connection string.
- Never commit .env files, passwords, API keys or database credentials.
- The projects are educational examples; production use requires additional security and
  deployment hardening.
